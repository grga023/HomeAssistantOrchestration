[NOTE]
====
Brojevi u tabelama i na graficima (uključujući `results.csv` i sve `fig-*.png`) su
trenutno *placeholder* (očekivane vrednosti iz link:04-methodology.adoc[04]) — samo

placeholder* dok se ne snime realna merenja na hardveru po postupku iz
link:05-runbook.adoc[05 — Runbook]. Tek tada ih zameni svojim merenjima.
====

== Kako se generišu grafikoni

. Popuni `results.csv` izmerenim brojevima (kolone `plain`, `tls`):
+
[source,csv]
----
metric,unit,plain,tls
heap_retained,KB,4,36
handshake_mean,ms,60,480
handshake_p95,ms,95,650
rtt_mean,ms,28,45
rtt_p95,ms,60,90
msg_wire_size,B,42,68
----
. Pokreni:
+
[source,bash]
----
pip install matplotlib
python3 plot_results.py            # čita results.csv, pravi fig-*.png
----
. Dobijaš `fig-heap.png`, `fig-handshake.png`, `fig-rtt.png`, `fig-packet.png`
  (colorblind-safe: plava = plain, narandžasta = TLS; 200 dpi za rad).

=== Wireshark snimci (dokaz enkripcije)

Ubaci screenshot-ove:

* `_[slika]_` — `tcp.port==1883 && mqtt`, *Follow TCP Stream*: čitljiv topic +
  payload (npr. „ON") + kredencijali → slajd „nezaštićeni baseline".
* `_[slika]_` — `tcp.port==8883 && tls`: TLS handshake + *opaque* Application Data
  → payload nečitljiv.

== Zaključak (checklist prema hipotezi)

* [ ] Memorijski overhead izmeren (~30–40 KB) → *TLS unosi merljivo opterećenje* ✓
* [ ] Handshake izmeren (~250–800 ms) → jednokratni trošak, dokumentovan kao takav
* [ ] Command RTT p95 < 200 ms na oba čvora → *degradacija unutar granica* ✓
* [ ] Wireshark: 1883 čitljiv, 8883 opaque → *dokaz sigurnosti* ✓
* [ ] Zaključak: sigurnost drastično povećana bez narušavanja UX-a → *hipoteza potvrđena*
